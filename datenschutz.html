Stand: 14. Oktober 2026. Diese Seite beschreibt die technisch erkennbaren Datenflüsse von Stremy 1.1.0 und der Download-Webseite. Sie ersetzt keine gegebenenfalls erforderliche vollständige rechtliche Datenschutzerklärung oder Anbieterkennzeichnung.

Die Webseite

Die Seite wird über GitHub Pages gehostet. GitHub verarbeitet technisch notwendige Verbindungsdaten, etwa IP-Adressen. Wir setzen auf der Seite keine eigenen Werbe- oder Tracking-Skripte ein. Die gewählte Akzentfarbe wird nur lokal im Browser gespeichert (localStorage).

Die Android-App

Zum Anzeigen von Livestreams, zur Anmeldung und für den Chat kommuniziert die App mit Twitch und gegebenenfalls mit eingebundenen Diensten für Bilder, Emotes und Streams. Twitch verarbeitet Anmelde- und Nutzungsdaten nach den eigenen Bedingungen. Anmeldedaten beziehungsweise Zugriffstoken und App-Einstellungen werden für die Funktion auf dem Gerät gespeichert.

Fehlerberichte

Im Release-Code ist Sentry/GlitchTip für Absturzdiagnosen eingebunden. Der konfigurierte Endpunkt lautet glitchtip.samfun.dev. Abhängig von der Auswahl zur Fehlerberichterstattung können Diagnoseereignisse an diesen externen Dienst übermittelt werden. Vor dem Versand entfernt die App bestimmte Nutzer- und Gerätefelder; dennoch können technische Informationen Bestandteil eines Berichts sein. Prüfe die entsprechende Einstellung in der App, wenn du keine Diagnoseberichte übermitteln möchtest.

Die APK und das GPL-3.0-Quellcodearchiv werden als Dateien über GitHub Releases bereitgestellt. GitHub verarbeitet beim Download Verbindungsdaten. Den Quellcode findest du auf der Release-Seite.
